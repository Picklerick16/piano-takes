# Piano Takes

A web app for iPad and a MIDI piano (built for a Thomann DP-95 B):

- **Record** what you play over USB MIDI, pause or stop, and edit right away.
- **Cut precisely**: select any stretch, nudge its edges in 1/10/100 ms steps, then *Cut out* or *Keep only this*. Undo/redo.
- **Sheet music** from what you played (switch it on per recording), optional metronome so bars line up.
- **Practice pieces** from MIDI files: falling notes, *Wait for me* and *Play along* modes, hands separately, speed, loop.
- **Coach**: feedback on wrong/missed notes, timing and evenness after every run, a 6-step ladder per section, and spaced-repetition reviews so learned sections don't fade.
- Export MIDI, WAV and sheet music PNG; back up everything to one file.

## Use it

Open **https://picklerick16.github.io/piano-takes/** in the free **MIDIWeb Browser** app on iPad (Safari can't read MIDI). Connect the piano's *USB to Host* port with a USB-C to USB-B cable.

Recordings are stored on the device, not in this repository.

Piano sound: Salamander Grand Piano V3 by Alexander Holm, CC BY 3.0. Sheet music engraving: [abcjs](https://github.com/paulrosen/abcjs) (MIT).
